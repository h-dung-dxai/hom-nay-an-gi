# Hôm nay ăn gì?

Web app gợi ý món ăn theo bữa (dựa vào giờ trên máy), dùng OpenAI. Mỗi món có nút mở Google Maps để tìm quán gần đây.

## Chạy trên máy

```bash
npm install
cp .env.example .env.local   # rồi điền OPENAI_API_KEY
npm run dev                  # mở http://localhost:3000
```

## Test

```bash
npm test
```
